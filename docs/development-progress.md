## 5. 当前对接事实

以下事实可默认作为后续协作基线：

- 首个正式版 `1.0` 已于 `2026-03-18` 发布
- 正式安装包类型为 `release-signed APK`
- 正式版本更新日志由 [CHANGELOG.md](../CHANGELOG.md) 提供
- 版本号规则固定为 `1.0 -> 1.1 -> ... -> 1.9 -> 2.0`
- 当前不依赖自建服务器，不包含云端账号系统
- AI 能力通过用户自行配置的第三方 API 扩展

## 6. 当前仍需持续增强的方向

以下项目不是“未做”，而是“第一版已落基础、后续继续增强”的方向：

- UI 细节打磨与更多机型适配
- 单词详情数据质量与覆盖度继续提升
- AI 计划调整结果在页面中的解释性展示
- 学习数据分析维度继续细化
- 导入词书的校验、清洗和错误提示继续加强
- 长期学习趋势、计划历史和 AI 建议链路继续完善
