WenwenLex v1.1 Design Preview

词书扩充、Excel 导入、多 API 管理、AI 音标补全

这是文文Lex 下一轮设计确认稿的静态预览。目标不是还原真实安卓界面细节，而是把功能结构先定下来： 内置词书从演示数据升级为可持续扩容的正式书库；导入只接 Excel；AI 从单配置升级为多配置快速切换； 音标支持单个补全、批量补全，并把结果写回数据库。

词库来源：开源可分发 + 可核验的公开整理版 导入格式：.xlsx / A列单词 / B列中文义 音标策略：优先双音标，允许单套保存 API 路由：全局默认 + 功能级覆盖

写回数据库后的规则

优先存双音标 英式和美式都保存；如果 AI 只返回一套，也允许先保存单套。
落库复用 补全结果直接存入词表，不重复请求同一个词。
来源标记 记录这条音标来自 AI 补全，便于后续人工修订或重跑。
这版设计的重点不是把每个细节一次做满，而是先把结构固定下来。只要你确认这个方向，我下一步就会继续给出 数据模型、数据库迁移、导入流程、AI 路由规则和发版升级策略，然后再把规格文档和实施计划写进仓库。
