# 文文Lex v1.8 导入闭环与统一发音源中心 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `v1.8` 的导入诊断与修复闭环、第一批质量补强、统一发音源中心、MiMo TTS、离线语音资产任务系统、低内存语音包安装、App 内更新日志和发版收口做成可正式发版的第一版能力。

**Architecture:** 保留当前“本地优先、无账号、无自建服务器、GitHub 云端发版”的边界，先完成 `Room 7 -> 8` 与备份 `v6 -> v7` 底座，再把导入闭环和质量补强接到现有词书流上，随后把“词典音频 / 本地引擎 / 云端 TTS / 预生成缓存”统一成发音源模型，最后补生成任务、低内存下载、缓存管理、更新日志与发版护栏。实现上继续沿用当前 Kotlin + Compose + Room + WorkManager 架构，不新开服务端。

**Tech Stack:** Kotlin, Jetpack Compose, Room, DataStore, WorkManager, kotlinx.coroutines, JUnit4, Android instrumented tests, Python/shell scripts, GitHub Actions.
