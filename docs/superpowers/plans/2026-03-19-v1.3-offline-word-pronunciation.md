# WenwenLex v1.3 Offline Word Pronunciation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver `v1.3` true offline word pronunciation on Android so any valid in-app English word, including imported vocabulary, can be synthesized locally with separate UK/US native voice packs and cached for repeat playback.

**Architecture:** Keep the existing `v3` Room schema stable for `v1.3.0` and persist only install/runtime state in `voice_packs` and `word_audio_assets`. Read richer metadata such as model family, memory budget, and license info from each pack's `manifest.json`, then layer a native Sherpa ONNX runtime bridge behind the existing pronunciation orchestrator so cached assets, native synthesis, and `1.2` fallbacks share one playback entry point.

**Tech Stack:** Kotlin, Jetpack Compose, Room, DataStore, WorkManager, Android `MediaPlayer`, prebuilt Sherpa ONNX Android runtime artifacts, JUnit, existing Android CI / Release workflows.

suspend fun synthesizeWord(word: Word, accent: PronunciationAccent): NativeSynthesisResult? {
    val normalized = normalizeWordForPronunciation(word.lemma) ?: return null
    val pack = voicePackRepository.getInstalledNativePack(accent) ?: return null
    val output = wordAudioRepository.buildGeneratedCacheFile(word.id, accent, normalized)
    runtimeLoader.load(pack.installDirFile).synthesizeWord(normalized, output)
    return wordAudioRepository.recordNativeGeneratedAsset(word.id, accent, output)
}
