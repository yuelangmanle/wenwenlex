# 文文Lex v1.5 AI 计划历史回溯、对比与解释增强 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把现有 AI 计划建议升级成“计划版本系统”，交付独立的 AI 计划中心、时间轴回溯、当前计划对比、解释页、小调整自动生效/大调整待确认、checkpoint 压缩记忆，以及数据库迁移与备份兼容。

**Architecture:** 保留现有 `AiStrategyCoordinator`、`AiMemoryRepository`、`Home` / `Study` 页主流程和底部四栏结构，不新增第 5 个 Tab。实现上先扩展 `plan_history` 主表和 `AiMemorySummary` 载体，再补计划判定与状态流转服务，最后接 AI 计划中心路由、首页/学习页快捷入口、对比/解释页面和备份恢复升级。

**Tech Stack:** Kotlin, Jetpack Compose, Room, DataStore, kotlinx.coroutines, JUnit4, Android instrumented tests, GitHub Actions.

class PlanAdjustmentEvaluator {
    fun evaluate(previous: PlanHistoryEntry?, candidate: PlanHistoryEntry): PlanSeverity {
        var changed = 0
        if (previous?.suggestedPace != candidate.suggestedPace) changed += 1
        if (previous?.suggestedModes.orEmpty() != candidate.suggestedModes) changed += 1
        if (previous?.recommendedFocus.orEmpty() != candidate.recommendedFocus) changed += 1
        return if (changed >= 2) PlanSeverity.MAJOR else PlanSeverity.MINOR
    }
}
