# 文文Lex v1.4 真实离线单词发音 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有发音链路上接通真实 `Sherpa ONNX` 单词级离线合成，交付英式 / 美式双高音质包、严格按口音切换、可复用缓存、结构化 telemetry 和 GitHub Release 发版闭环。

**Architecture:** 保持现有页面入口和大部分 `v1.3` 模块边界不变，只把真正的 runtime 执行、语音包校验、版本化缓存和口音级激活补齐。仓库内只保留 pack 模板、许可证和上游来源描述；真实模型文件由 GitHub Actions 在云端按固定版本拉取并组装，避免把数百 MB 二进制塞进 git，同时保持 Release 资产可复现。

**Tech Stack:** Kotlin, Jetpack Compose, Room, DataStore, WorkManager, Android instrumented tests, Sherpa ONNX Android runtime, GitHub Actions, GitHub Releases, Bash, Python.
