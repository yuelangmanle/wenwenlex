# WenwenLex v1.1 Lexicon, Import, and AI Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver `v1.1` with real built-in lexicons, `.xlsx` import, AI-assisted import normalization, multi-API management, dual-phonetic enrichment, and a safe `1.0 -> 1.1` database upgrade path.

**Architecture:** Keep the single `app` module, but split `v1.1` work into focused slices: Room schema and migration, import/enrichment domain logic, feature-layer UI flows, and release/backup compatibility. Continue using local-first storage and make AI an enhancement layer that fills or normalizes data only after local parsing and user confirmation.

**Tech Stack:** Kotlin, Jetpack Compose, Navigation Compose, Room, DataStore, Android Keystore, WorkManager, `org.json`, Android document picker APIs, ZIP/XML parsing for `.xlsx`, JUnit, Robolectric, Compose UI tests, connected Android tests.

```kotlin
class XlsxBookImporter(
    private val tableReader: XlsxXmlTableReader = XlsxXmlTableReader(),
) : BookImportParser {
    override fun parse(inputStream: InputStream): ImportedBook {
        val rows = tableReader.readFirstSheet(inputStream)
        val words = rows.mapNotNull { row ->
            val lemma = row.firstOrNull()?.trim().orEmpty()
            if (lemma.isBlank()) return@mapNotNull null
            ImportedWord(
                text = lemma,
                meanings = row.getOrNull(1).orEmpty()
                    .replace('，', ',')
                    .split(',')
                    .map(String::trim)
                    .filter(String::isNotEmpty),
            )
        }
        return ImportedBook(
            metadata = ImportedBookMetadata(id = "imported-xlsx", title = "Excel 导入词书"),
            words = words,
        )
    }
}
```

```kotlin
data class ParsedPhoneticFill(
    val phoneticUk: String? = null,
    val phoneticUs: String? = null,
)

fun Word.withPhonetics(result: ParsedPhoneticFill, source: String): Word =
    copy(
        phonetic = result.phoneticUk ?: result.phoneticUs ?: phonetic,
        phoneticUk = result.phoneticUk,
        phoneticUs = result.phoneticUs,
        phoneticSource = source,
        phoneticStatus = when {
            !result.phoneticUk.isNullOrBlank() && !result.phoneticUs.isNullOrBlank() -> "complete"
            !result.phoneticUk.isNullOrBlank() || !result.phoneticUs.isNullOrBlank() -> "partial"
            else -> "empty"
        },
    )
```
