# 文文Lex v1.7 学习效果增强与交付护栏 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把动态复习、日/周/阶段目标、升级安全、发版护栏和诊断导出做成 `v1.7` 第一版正式能力，并完成数据库迁移、备份升级、页面接入和云端发版准备。

**Architecture:** 保留当前四大主导航、现有学习流和 GitHub 云端发版基线，不新增账号、服务器或新的底部 Tab。实现上先补学习信号与目标数据底座，再让动态复习引擎接管今日队列和学习反馈，随后接目标页面、统计页与诊断中心，最后补升级安全、发版脚本和发版文档。

**Tech Stack:** Kotlin, Jetpack Compose, Room, DataStore, kotlinx.coroutines, JUnit4, Android instrumented tests, shell scripts, GitHub Actions.

- [ ] **Step 3: 实现优先级引擎与熟练度分层**

```kotlin
data class RankedReviewItem(
    val wordId: Long,
    val priorityScore: Float,
    val bucket: String,
)

class ReviewPriorityEngine {
    fun rank(records: List<LearningRecord>, now: Instant): List<RankedReviewItem> =
        records.map { record ->
            val score = overdueWeight(record, now) + mistakeWeight(record) + latencyWeight(record)
            RankedReviewItem(
                wordId = record.wordId,
                priorityScore = score,
                bucket = if (record.consecutiveMistakeCount >= 2) "rescue" else "review",
            )
        }.sortedByDescending(RankedReviewItem::priorityScore)
}
```
