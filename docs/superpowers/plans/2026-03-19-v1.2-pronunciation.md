# WenwenLex v1.2 Pronunciation And Voice Pack Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver `v1.2` mixed pronunciation playback with dictionary audio caching, offline voice pack download/mount, system TTS fallback, and telemetry hooks for later AI analysis.

**Architecture:** Extend the existing single-module Android app with a dedicated pronunciation domain slice. Keep word data and playback orchestration local-first: Room persists audio assets and voice packs, DataStore holds preferences, WorkManager handles downloads, and feature screens talk to a small orchestration API instead of directly touching network or TTS engines.

**Tech Stack:** Kotlin, Jetpack Compose, Room, DataStore, WorkManager, Android `TextToSpeech`, `MediaPlayer`, `HttpURLConnection` or existing HTTP stack, `org.json`, JUnit, Robolectric, Android instrumented tests.

suspend fun playWord(word: Word, accent: PronunciationAccent): PlaybackResult {
    repository.findReadyCache(word.id, accent)?.let { return player.play(it) }
    service.resolve(word.lemma, accent)?.let { remote ->
        val cached = repository.cache(remote, word.id, accent)
        return player.play(cached)
    }
    offlineTts.playWord(word, accent)?.let { return it }
    return systemTts.playWord(word, accent)
}
